## Default Permission

Allows an OAuth sign-in to be presented in the platform's own browser sheet.

#### This default permission set includes the following:

- `allow-authorize`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`web-auth:allow-authorize`

</td>
<td>

</td>
</tr>

<tr>

</td>
